# Технический промт: сайт салона наращивания ресниц «J.Lash»

## 1. Общее описание проекта

Разработать многостраничный сайт для салона наращивания ресниц **J.Lash**
(г. Есик, Алматинская область, Казахстан).

**Главный приоритет проекта — SEO и локальный поиск.** Сайт должен:

- отлично индексироваться поисковыми роботами Яндекса и Google;
- выходить в топ по запросам вида «нарастить ресницы рядом», «наращивание
  ресниц Есик», «наращивание ресниц Алматинская область»;
- быть корректно связан с Яндекс.Картами и 2ГИС.

## 2. Технологический стек

- **Фреймворк:** Next.js (React + TypeScript)
- **Стилизация:** Tailwind CSS
- **Анимации/UI-компоненты:** библиотека [reactbits.dev](https://reactbits.dev)
  (копирование нужных компонентов через CLI/вручную)
  первый экран главной страницы - https://reactbits.dev/backgrounds/ballpit
  Logo.png - https://reactbits.dev/animations/metallic-paint
  услуги - https://reactbits.dev/components/magic-bento
  кнопки - https://reactbits.dev/animations/star-border
- **Рендеринг:** SSR или SSG (не чистый CSR/SPA) — критично для индексации
  контента поисковыми роботами
- **i18n:** русский + казахский (билингва), через встроенный i18n-роутинг
  Next.js (`/ru/...`, `/kk/...`) с `hreflang`-тегами между версиями
- **Хостинг:** Netlify (бесплатный тариф на старте; Netlify официально
  поддерживает Next.js SSR и API-роуты через собственный Next.js runtime)
- **Домен:** пока не куплен, сайт будет на поддомене Netlify

## 3. Структура сайта (страницы)

1. **Главная** — краткое УТП, ключевые услуги, CTA на мессенджеры, блок отзывов
2. **Услуги** — список услуг с ценами (см. п.6). На старте — единая страница;
   архитектуру закладывать так, чтобы позже легко вынести каждую услугу на
   отдельный URL (`/uslugi/[slug]`) без переделки структуры
3. **Цены** — таблица цен (либо объединить с «Услугами», если решат позже)
4. **Портфолио** — фотографии работ (на старте — плейсхолдеры/заглушки)
5. **Блог / Статьи** — раздел для SEO-контента (статьи про уход за ресницами,
   виды наращивания и т.п.)
6. **Мы на карте** — встроенные виджеты Яндекс.Карт и 2ГИС с меткой салона
7. **Контакты** — адрес, телефон (заглушка), часы работы (заглушка), кнопки
   мессенджеров

## 4. SEO-требования

- SSR/SSG-рендеринг всех страниц — HTML с контентом должен отдаваться сразу,
  без ожидания выполнения JS
- Уникальные `title`/`description` под каждую страницу, с локальными
  ключевыми словами (город Есик, Алматинская область)
- Open Graph + Twitter Card метатеги на каждой странице (через Next.js
  Metadata API) — `og:title`, `og:description`, `og:image` (использовать
  `logo.png`), чтобы ссылка красиво рендерилась при отправке в WhatsApp/
  Telegram/Instagram
- Структурированные данные JSON-LD по схеме `schema.org/BeautySalon` (или
  `LocalBusiness`): название J.Lash, адрес, геокоординаты, телефон, часы
  работы (поля — заглушки до получения реальных данных)
- `sitemap.xml` и `robots.txt`
- `hreflang` теги для ru/kk версий
- Регистрация и подтверждение сайта в Яндекс.Вебмастере и Google Search
  Console (после деплоя)
- Создание профилей «Яндекс.Бизнес» и 2ГИС с нуля — название, адрес и телефон
  на сайте и в профилях должны точно совпадать (NAP-консистентность)

## 5. Функциональность

- **Связь с клиентом:** без формы онлайн-записи — кнопки-ссылки на WhatsApp
  (`wa.me/...`), Telegram (`t.me/...`) и Instagram, с предзаполненным текстом
  сообщения
- **Отзывы клиентов:** блок с возможностью оставить отзыв прямо на сайте.
  Требует backend (API-роут + хранилище — например Netlify Functions +
  Supabase/Airtable/аналог) и простую модерацию перед публикацией (защита от
  спама — капча или honeypot-поле)
- **Карта:** страница «Мы на карте» со встроенными Яндекс.Карты и 2ГИС
  виджетами
